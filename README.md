# Pattern Recognition in Machine Learning

Projeto focado em fundamentos de reconhecimento de padroes e classificacao.

## Estrutura

- `notebooks/01_language_identification_feature_engineering.ipynb`
- `notebooks/02_breast_cancer_svm_pipeline.ipynb`

## Resultados numericos do escopo

- Dataset de cancer de mama (Wisconsin): `569 amostras`
- Divisao treino/teste: `80% / 20%`
- Modelo principal: `SVM (RBF)` com pre-processamento
